# Historical plans

Files in this directory record the architecture and vocabulary in force when a
milestone was designed. They are evidence, not the current interface contract.
In particular, plans written before 2.0 may refer to the retired
`dlightrag_ai`, `dlightrag_agent`, and `dlightrag_rag` import roots or to their
former standalone distributions. Do not copy those paths into current code.

Use `docs/architecture.md`, `docs/domain-language.md`, and
`docs/configuration.md` as the authoritative current design.
